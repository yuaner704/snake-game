# 贪吃蛇 🐍

一个单文件的 HTML5 贪吃蛇小游戏，用 Canvas 绘制，没有任何依赖，打开 `index.html` 就能玩。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 暂停 / 继续 | `空格` |
| 重新开始 | `R` |
| 手机 | 在棋盘上滑动屏幕 |

- 吃到食物得 10 分。
- 每得 50 分加速一次，最快 65ms 走一步。
- 撞墙或撞到自己游戏结束。
- 最高分存在浏览器 `localStorage` 里，刷新也不会丢。
- 填满整个棋盘即为通关。

## 本地运行

直接双击 `index.html` 即可。想用本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 实现说明

- 20 × 20 的网格，`requestAnimationFrame` 驱动主循环，逻辑步进和渲染分离。
- 转向输入进队列（最多缓存 2 个），避免同一帧内连按两次导致反向自杀。
- 蛇尾即将移开的那个格子不算碰撞，贴着尾巴走不会误判死亡。
- 画布按 `devicePixelRatio` 缩放，在高分屏上不糊。
- 页面切到后台时自动暂停，切回来不会瞬间走一大串步数。
